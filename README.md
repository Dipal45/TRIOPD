# 🧠 TRIOPD – Multimodal Parkinson’s Disease Detection

### Voice • Handwriting • Gait Analysis

TRIOPD is a multimodal machine learning framework designed to explore Parkinson’s Disease (PD) screening using three non-invasive digital biomarkers: **handwriting patterns, voice recordings, and gait characteristics**.

The project combines individual machine learning pipelines to analyse different movement and speech patterns associated with Parkinson’s Disease. It explores weighted soft voting (late fusion) to integrate predictions from the three modalities into a common framework.

---

## 🚀 Project Overview

Parkinson’s Disease is a progressive neurological disorder that affects motor functions, speech, coordination, and movement.

TRIOPD explores how machine learning can analyse measurable characteristics from handwriting, voice, and walking patterns to support research into Parkinson’s Disease screening.

Instead of relying on a single modality, the framework investigates three independent analysis modules:

- ✍️ **Handwriting Analysis:** Examines spiral and meander drawing patterns to identify motor-related variations.
- 🎙️ **Voice Analysis:** Extracts acoustic and spectral features from speech recordings.
- 🚶 **Gait Analysis:** Analyses stride-time patterns and walking characteristics to identify movement variations.

The predictions from individual models are explored through a weighted soft-voting approach.

## ✨ Key Features

- Multimodal Parkinson’s Disease screening framework.
- Handwriting-based motor pattern analysis.
- Voice-based acoustic and spectral analysis.
- Gait-based statistical and temporal feature analysis.
- Machine learning classification using tree-based models.
- Weighted soft-voting-based prediction fusion.
- Participant-level model validation to reduce data leakage.
- Model performance evaluation using accuracy, F1-score, sensitivity, specificity, confusion matrices, and ROC-AUC.
- Web-based interface for analysing different modalities and generating reports.

## 🔬 Methodology

### 1. Handwriting Analysis

The handwriting module uses the Spiral HandPD dataset.

It analyses spiral and meander drawings to extract numerical features representing drawing patterns and motor characteristics.

**Objective:** Identify handwriting-related variations associated with Parkinson’s Disease.

### 2. Voice Analysis

The voice module uses a Parkinson’s Disease speech dataset.

Acoustic and spectral features are extracted from voice recordings.

**Features include:**
- Mel-Frequency Cepstral Coefficients (MFCC)
- Chroma
- Spectral Contrast
- Zero-Crossing Rate
- RMS Energy
- Spectral Centroid
- Spectral Bandwidth

**Objective:** Identify speech and vocal characteristics that may help distinguish Parkinson’s Disease samples from healthy controls.

### 3. Gait Analysis

The gait module uses the PhysioNet Gait in Parkinson’s Disease dataset.

It extracts statistical, temporal, frequency-domain, and variability-based features from stride-time series.

The experimental implementation uses 95 engineered gait features.

**Objective:** Identify walking-pattern variations associated with Parkinson’s Disease.

### 4. Multimodal Fusion

The framework explores late fusion using weighted soft voting.

The prediction probabilities generated by the individual modality classifiers are combined to produce a final prediction.

The fusion experiment also highlights challenges involving participant alignment, probability calibration, and dataset compatibility.

## 📊 Experimental Results

The following results are reported in the project thesis.

| Modality | Accuracy | Other Metrics |
|---|---:|---|
| Handwriting | 82% | F1-score: 0.80 |
| Voice | 99.12%* | Sensitivity: 100%, Specificity: 98.26% |
| Gait | 78.26% | Sensitivity: 92.31%, Specificity: 60% |
| Multimodal Fusion | Not established | AUC: 0.477 |

*The voice accuracy represents a particular reported evaluation, not a confirmed overall performance across all evaluation settings.*

### Important Observations

- Handwriting features demonstrate potential for identifying motor-related variations.
- Voice features achieved high reported classification performance in one evaluation.
- The gait model demonstrated high sensitivity but comparatively lower specificity.
- The multimodal fusion experiment achieved an AUC of 0.477, indicating that the current fusion approach requires further improvement.

**These results are experimental and dataset-specific. They should not be interpreted as established clinical diagnostic performance.**

## 📂 Datasets Used

The project explores three publicly available datasets:

1. **Spiral HandPD Dataset** – Handwriting and drawing patterns.
2. **Parkinson’s Disease Speech Dataset** – Acoustic and spectral voice characteristics.
3. **PhysioNet Gait in Parkinson’s Disease Dataset** – Gait and stride-time measurements.

The datasets are processed independently for their respective classification tasks.

## 🔮 Future Scope

The project identifies several opportunities for future development:

- Expanding datasets with more diverse participants.
- Improving model performance and reducing overfitting.
- Strengthening participant-level validation.
- Improving multimodal data synchronization and fusion.
- Introducing pose-estimation-based gait analysis.
- Supporting longitudinal monitoring of digital biomarkers.
- Conducting clinical validation with healthcare professionals.
- Improving privacy, authentication, and secure data storage.

## ⚠️ Limitations

- The three modalities currently rely on separate datasets.
- The datasets do not contain fully participant-aligned observations across all modalities.
- The current fusion experiment does not demonstrate improved predictive discrimination.
- Further validation using larger and participant-aligned datasets is necessary.
- The current gait module performs binary classification rather than independent clinical severity estimation.

## 🎯 Project Objective

The primary objective of TRIOPD is to explore the integration of multiple non-invasive digital biomarkers into a common machine learning framework for Parkinson’s Disease screening research.

The project demonstrates the potential of combining handwriting, speech, and gait analysis while identifying practical challenges in multimodal machine learning.
