# TRIOPD - Multimodal AI-Assisted Parkinson's Disease Assessment

## Overview
TRIOPD analyzes Handwriting, Walking/Gait, and Voice using machine learning models fused via fuzzy logic to estimate Parkinson's Disease risk.

## Quick Start

- Node.js 16+
